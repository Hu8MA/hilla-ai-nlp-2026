## About this course

Natural Language Processing (NLP) is the field of AI that helps computers **understand, process, and generate** human language.

In this course, you will learn how computers work with text, step by step: from cleaning raw text, to counting words, to understanding sentence structure, and finally to real applications like sentiment analysis and machine translation.

All lab work is done in **plain Python** and **Jupyter notebooks**, and all homework is submitted through **GitHub**.
